How it works

Three steps. That's it.

  1. Register with a GSP

    Register your GSTIN for the API interface through a GSP on the government e-Invoice portal. You only do this once.

  2. Switch it on

    Go to Menu → Configuration → Invoice and turn on the e-Invoice toggle, once per company.

  3. Generate the IRN

    Check the details and hit generate. The IRN, acknowledgement number and date come back from the portal automatically.

Questions

e-Invoices: questions

Still unsure? Install the app and try it free for 7 days.

Do I need to upload a JSON file to generate an e-invoice?

No. Livekeeping sends the invoice details directly to the IRP through the GSP connection, so there is no manual JSON file to prepare or upload.

How do I fix an e-invoice after the IRN is generated?

GST rules don't allow editing an IRN once it's generated, but you can cancel the e-invoice within 24 hours, right from Livekeeping.

Can I generate an e-invoice from my phone?

Yes. e-Invoice generation works the same way on mobile and web, so you can raise one from your sales voucher on either platform.

Can I generate an e-Way Bill and e-Invoice together?

Yes. When you save the voucher, choose whether to raise an e-Way Bill, an e-Invoice, or both, depending on what the transaction needs.
